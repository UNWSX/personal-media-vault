Use the application primarily for personal, non-commercial metadata
management. Users are responsible for:

- complying with each service's terms, robots rules, and access limits;
- making only low-frequency, user-initiated requests;
- stopping when a service returns HTTP 401, 403, 429, a CAPTCHA, or another

- not bypassing authentication, paywalls, CAPTCHAs, or technical restrictions;
- not building or operating large-scale scraping or redistribution systems;
- obtaining permission before commercially using or publicly redistributing

encrypted with Windows DPAPI after the user explicitly saves or imports it.
