# 2.5.17 修改清单

- `LICENSE`
  - 添加项目原创代码的 MIT 许可证。
- `THIRD_PARTY_NOTICES.md`
  - 添加历史参考、第三方服务、内容归属和使用边界说明。
- `app/server.py`
  - 只使用用户显式保存或导入的豆瓣登录态。
  - 取消图片主机轮换。
  - 对受限制的上游访问停止后续请求。
  - 后台补分任务在访问受限时进入 `blocked` 状态，不再自动重试。
- `app/batch_imdb.py`
  - 默认及最小请求间隔调整为 1 秒。
- `app/batch_enhanced_ratings.py`
  - 默认及最小请求间隔调整为 1 秒。
- `app/web/app.js`
  - 更新登录态导入提示。
  - 网页版定期发送活动心跳，并在页面关闭时通知本地服务。
  - 网络评分缺失时提供重新补分按钮。
- `app/web/index.html`
  - 增加手动导入和第三方内容提示。
- `app/server.py`
  - 网页版模式下增加空闲和离页关闭机制。
- `tests/test_api_phase1.py`
  - 新增插件 Cookie 不自动读取、图片主机不轮换、访问限制停止后续请求测试。
- `shell/Program.cs`
  - 支持独立版把可执行文件放在“程序”子目录，并把媒体数据放在上一级“数据”目录。
  - 关闭窗口时结束当前连接的服务，即使该服务由网页版启动。
- 发布包
  - 独立版减少无用的批量工具和开发文件，根目录提供“双击启动影音库.exe”。
  - Obsidian 修复包把批量工具统一放进“工具”目录。
- `launcher/Launcher.cs`
  - 新增无控制台窗口的小型启动器，从根目录启动“程序”内的主应用。
- `launcher/WebLauncher.cs`
  - 新增本地网页版启动器，自动启动服务并打开默认浏览器。
