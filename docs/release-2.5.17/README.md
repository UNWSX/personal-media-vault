# 影音库 2.5.17 合规加固版

发布日期：2026-11-08

本版本保留 2.5.16 的媒体浏览、搜索、添加、评分、详情编辑、封面修复、
删除、备份和 Obsidian 集成功能，重点调整第三方元数据的访问边界。

主要变化：

- Obsidian 豆瓣插件登录态改为显式导入，不再后台静默读取插件配置。
- 豆瓣图片请求不再轮换至其他图片主机。
- 批量评分工具默认且至少保持 1 秒请求间隔。
- 遇到 401、403、418、429 时停止继续访问对应服务。
- 新增 MIT License、第三方声明和非官方工具使用边界。
- 独立版根目录提供“双击启动影音库.exe”和“打开本地网页版.exe”。
- 本地网页版入口会自动定位服务、打开默认浏览器并复用同一数据目录。
- 运行库和服务集中放入“程序”目录。
- 关闭网页后，本地服务会在短暂宽限期后自动退出。
- 桌面窗口关闭时会结束它当前连接的服务，包括网页版先前启动的服务。
- Obsidian 修复包将批量工具集中放入“工具”目录。

本版本不修改 Markdown 数据格式，不执行迁移，也不改变真实 Vault 中的笔记。
