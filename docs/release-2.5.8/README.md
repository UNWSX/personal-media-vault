# 影音库 2.0 · 2.5.8

发布日期：2026-11-08

## 本版内容

- 新建或通过豆瓣导入条目时自动抓取外部评分，不再要求导入后另跑批量工具。
- 电影、剧集自动尝试 IMDb、Rotten Tomatoes、Metacritic。
- 豆瓣导入同时保留豆瓣评分；动画剧集额外尝试 Bangumi。
- 已有字段不会被自动抓取覆盖。
- 抓取失败只保留空值，不阻挡条目创建，不写入猜测评分。
- Wikidata 支持系统代理，并增加临时失败重试。
- 批量缓存只复用成功匹配；旧的 `no_match/error` 会在下次运行时重新查询。
- 新建条目会尽量保存 `originalTitle`，方便后续跨语言评分查询。
