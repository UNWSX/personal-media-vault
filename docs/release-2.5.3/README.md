# 影音库 2.0 · 2.5.3 正式版

发布日期：2026-11-07

## 本版内容

- 电影、剧集详情页新增独立的 IMDb 0–10 评分。
- IMDb 评分由标题、年份和媒体类型唯一匹配后自动写入，不在界面手动填写。
- 烂番茄没有可靠数据时不显示烂番茄模块，不再显示“未收录”。
- IMDb 没有可靠数据时同样不显示 IMDb 模块。
- 新导入电影、剧集会同时尝试查询豆瓣原名对应的 IMDb 与 Rotten Tomatoes 评分。
- 已有评分字段默认不覆盖。

## 真实 Vault 批量结果

197 条电影/剧集预演结果：

- 可靠匹配并写入 IMDb 评分：97
- 无可靠匹配：99
- 歧义候选：1
- 查询错误：0
- 写入失败：0
- 外部修改冲突：0

97 篇仅增加 `imdbScore`。正文、附件、链接、Rotten Tomatoes 指数和其他 YAML
字段保持原样；未可靠匹配的记录未被修改。

## 兼容性

- API 版本仍为 `2.0.0`，协议版本仍为 `1`。
- Markdown 目录、文件名、正文和 Obsidian 链接不变。
- `imdbScore` 使用已有 0–10 评分字段规范。
