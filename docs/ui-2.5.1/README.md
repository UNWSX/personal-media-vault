# 影音库 2.5.1 界面与评分回归

日期：2026-11-07

## 修改项

1. 页面右侧滚动条改为自绘轨道，从顶栏下方开始显示。
2. 状态统一为“未完成 / 已完成”，移除未开始、进行中等筛选。
3. 排序菜单固定为：标题、发行、完成时间、我的评分、网络评分。
4. 详情页恢复 1.0 的双栏布局和二元状态开关。
5. 外部评分恢复固定来源：
   - 游戏：Metacritic 0–100。
   - 电影、剧集、图书：豆瓣 0–10。
   - 外部评分为只读字段，不在详情页手动填写。
6. `myScore` 继续由用户填写，与外部评分独立。
7. 增加 `rottenTomatoesScore`。电影和剧集详情页在豆瓣/ Metacritic 右侧显示烂番茄指数。
8. 新导入电影和剧集时会最佳努力自动查询 Rotten Tomatoes；查询失败不阻断导入。
9. 移除“统一比较分”及对应 UI。
10. 修复详情简介在窗口化/非全屏时被 flex 压缩并出现内部滚动的问题；现在简介完整展开，整页统一滚动。

## 分数补齐

用户确认旧版评分来源固定后，使用迁移引擎补充：

```text
Plan eafd90ac-f4f3-4f46-a80e-dd9750761816
  APPLIED: 291

Plan e9e94338-ad25-414b-ab73-b6bc5283bd77
  APPLIED: 2

总计：
  metacriticScore: 92
  doubanScore: 201
  无评分保持原状: 2
```

两个旧游戏评分 `6.8`、`7.7` 按 1.0 的显示规则换算为 Metacritic `68`、`77`。旧 `score`、`scoreStar` 均保留。

## 兼容

- 旧版 JSON API 仍可提交 `score`、`status`。
- 旧 API 写入 `score` 时同步对应类型的专用评分字段。
- 既有 `rottenTomatoesScore` 原值保留；不伪造缺失的烂番茄数据。
- `progressStatus` 数据仍保留，但新版 UI 只显示完成位。
