# 2.5.1 修改文件清单

## 前端

- `app/web/index.html`
  - 状态筛选项改为未完成/已完成。
  - 排序菜单改为独立标签 + 图标样式。
  - 移除排序按钮右侧的小箭头。
  - 增加页面滚动轨道。
- `app/web/app.js`
  - 二元状态筛选与开关。
  - 移除顶部无实际用途的“我的均分”统计。
  - 详情页观看状态改为居中等宽双选控件，保留原保存与回滚逻辑。
  - 完成时间输入框按评分行实际内容宽度动态收窄，使日历图标中心与评分末尾“评”字中心对齐。
  - 唯一匹配且值为空的状态 Callout 会在更新状态时安全补写目标值。
  - 固定评分来源与只读展示。
  - 烂番茄显示。
  - 排序菜单顺序和标签。
  - 自绘页面滚动条；顶端定位在首行卡片顶部上方 17px，滚动期间保持固定。
  - 移除统一比较分。
- `app/web/style.css`
  - 滚动轨道定位在首行卡片顶部上方 17px。
  - 外部评分在详情左半栏居中对称排列，来源名称与完整分数居中对齐，左侧字段文字向右微调。
  - 观看状态整体在左半栏居中，用轻底色等宽双选高亮替代左右滑动圆点。
  - 完成时间字段保持左对齐并随评分行内容宽度对齐。
  - 筛选行标签与控件、详情标签胶囊、日期文字与日历图标统一使用垂直中心对齐。
  - 类型筛选图标按 Emoji 字形差异做 1–2px 光学居中校正。
  - 调整排序菜单、评分区和简介布局。
  - 修复详情简介收缩。
  - 移除评分卡片边框和底色，缩小评分区间距。
- `app/web/compat_logic.js`
  - 可编辑字段注册表增加烂番茄评分。

## 后端

- `app/server.py`
  - 支持 `rottenTomatoesScore` 创建和读取。
  - 电影/剧集导入时自动查询烂番茄。
- `app/media_compat.py`
  - 增加烂番茄合法范围和归一化。
  - 旧 `score` 按媒体类型固定映射到豆瓣/Metacritic。
  - 旧客户端修改 `score` 时同步对应专用评分。
- `app/migration.py`
  - 处理旧游戏 10 分制评分到 Metacritic 百分制的换算。
  - 避免 Decimal 与 JSON 数字误报差异。
  - 已有且一致的 L1 评分不再生成审核组。
