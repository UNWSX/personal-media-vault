# 影音库 2.0 · 2.5.6 正式版

发布日期：2026-11-08

## 本版内容

- 恢复并扩展 Wikidata 稳定作品编号查询，支持 IMDb `P345`、烂番茄
  `P1258` 和 Metacritic `P1712`。
- 历史缓存中的 `wikidataId` 可直接刷新，不再重新依赖翻译标题猜测作品。
- 电影、剧集增加 Metacritic 评分；剧集按季读取独立评分。
- Metacritic 季名改为严格匹配，拒绝续作同名前缀和未收录的 `0` 分占位。
- 新增中文本地化标题的人工核对别名，作为作品编号不可用时的回退。
- 评分区支持 1－5 个来源：1－4 个单行居中，5 个采用上 3 下 2。
- 5 个评分使用两行独立居中布局，行内间距为 `48px`。
- 改进标题系列排序，识别罗马数字季号和 `Part` 分部，并按发行年份排列。
- API、Markdown 目录、文件名、正文结构和 Obsidian 链接保持不变。
