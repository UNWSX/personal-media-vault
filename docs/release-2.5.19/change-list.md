# 2.5.19 修改清单

- `app/server.py`
  - 豆瓣电影/剧集导入在写入前读取详情类型，并允许详情覆盖搜索筛选。
  - 使用 `type`、`subtype`、`is_tv`、`episodes_count` 判断 TV 条目。
  - 重复导入跨 `movie` / `teleplay` 目录查重。
  - 旧错误条目通过备份和原子写入修正 `type`，随后迁移目录并清理缓存。
  - 图书与游戏分支增加实际类型一致性测试。
- `app/web/app.js`
  - 类型被纠正时明确提示用户。
- `app/server.py`
  - 将自动评分需要的主标题、豆瓣原名、动画桥接、Wikidata 稳定 ID、
    分季/Part、平台查询缓存和写回计划直接内建到自动评分入口。
  - 删除自动入口对 `batch_enhanced_ratings.build_plan()` 的调用。
  - 旧笔记没有 `originalTitle` 时，优先使用豆瓣 ID 获取原名。
  - IMDb 的多个精确候选中，只有在最佳搜索排名至少领先其他候选 5 倍时
    才自动选分；接近排名继续判为歧义。
  - 访问限制任务从永久 `blocked` 改为冷却一小时自动重试。
  - 启动评分 Worker 时自动恢复旧版遗留的 `blocked` 任务。
- `app/web/compat_logic.js`
  - 修复数字前缀系列标题在去重后缀后误回退原始标题的问题。
- `tests/`
  - 验证电影筛选结果可保存为剧集。
  - 验证旧错误电影笔记迁移到剧集目录。
  - 验证图书与游戏导入类型不漂移。
  - 验证自动评分不调用批量工具。
  - 验证豆瓣 ID 优先用于恢复原名。
  - 验证 IMDb 同名同年候选消歧。
  - 验证访问限制任务自动重排。
  - 验证 `007` 系列按发行日期从旧到新排列。
