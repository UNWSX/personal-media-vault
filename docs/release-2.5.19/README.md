# 影音库 2.5.19

发布日期：2026-11-09

本版针对添加媒体后的自动评分与标题排序做修正：

- 豆瓣导入以详情中的真实类型为准，电影/剧集选择错误会自动纠正。
- 重复导入旧错误条目时会迁移到正确目录，不产生重复记录。
- 图书与游戏使用独立端点校验，增加类型不漂移测试。
- 自动评分不再依赖批量增强工具。
- 旧笔记可以通过豆瓣条目 ID 重新取得 `originalTitle`。
- IMDb 同名同年候选可使用搜索排名做保守消歧。
- 访问受限任务会自动冷却重试，升级时恢复旧版遗留的 `blocked` 任务。
- `007`、`1917` 等数字前缀系列在标题排序时能正确按发行日期从旧到新排列。

普通电影和电视剧仍按豆瓣、IMDb、烂番茄、Metacritic 获取可用评分；
动画额外获取 Bangumi。来源本身没有可公开读取的评分时，不会猜测或伪造。
