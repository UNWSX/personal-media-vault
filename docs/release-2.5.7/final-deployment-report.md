## 问题原因

2.5.6 及更早版本关闭窗口时，只保存当前
`width`、`height`、`x`、`y`，没有保存窗口是否最大化。

用户在最大化状态下关闭后，状态文件可能保存为接近屏幕尺寸、且位置为负数的
普通窗口数据。下次启动按普通窗口恢复时，WebView2 内容区贴近屏幕边缘；再次
最大化后，Windows 才重新校正窗口，因此问题看起来像是“最大化后自动修复”。

实际遗留状态示例：

```json
{"width":2576,"height":1408,"x":-8,"y":-8,"theme":"light"}
```

## 修复

- 保存窗口时增加 `maximized`。
- 最大化状态保存 `RestoreBounds`，不再把最大化尺寸当成普通窗口尺寸。
- 启动时恢复真正的最大化状态。
- 对旧状态中接近全屏、负坐标的尺寸按最大化兼容处理。
- 普通窗口尺寸和位置均限制在当前显示器工作区。
- 排序按钮保持上一版结构和自动宽度，将图标与文字整体向左微移 3px。
