# 影音库数据迁移助手 1.0.0

用于把旧版本地数据安全合并到新版本。工具不会删除源目录，也不执行同步删除。

## 下载哪个文件

从发布页下载：

```text
media-vault-data-migration-1.0.0-win-x64.zip
```

解压后运行：

```text
影音库数据迁移助手.exe
```

同一发布页中的 `data-migration-1.0.0-SHA256SUMS.txt` 只用于校验文件，
不是可执行程序；`personal-media-vault-2.5.19-source.zip` 是源代码包。

## 使用前

1. 关闭影音库桌面版和网页版。
2. 使用 Obsidian 的用户先关闭 Obsidian。
3. 保留旧版本压缩包或整个旧数据目录。
4. 确认磁盘剩余空间大于旧数据和新版目标目录备份的总大小。

## 操作

1. 启动“影音库数据迁移助手.exe”。
2. 选择旧版程序目录或旧版“数据”目录。
3. 选择新版程序目录或新版“数据”目录。
4. 选择同名文件策略：
   - 仅补充缺失文件；
   - 源文件较新时覆盖（推荐）；
   - 始终覆盖同名文件。
5. 点击“扫描并预览”，检查文件列表。
6. 点击“执行迁移”并确认。
7. 打开新版影音库，检查媒体数量、封面、附件和报告。

程序会自动识别程序根目录下的“数据”子目录。默认迁移：

- `媒体库`（独立版媒体数据）；
- `02-电影阅读`（Obsidian 媒体数据）；
- `attachments`；
- `.media-app`。

如果选择了其他结构，可启用“迁移整个所选文件夹（高级）”。

## 安全规则

- 源目录和目标目录不能相同，也不能互相包含。
- 执行前完整备份目标目录。
- 每个文件先复制到临时文件，校验 SHA256 后再原子替换。
- 预览后源或目标文件发生变化时停止执行，要求重新预览。
- 跳过 `apply.lock`、临时文件、符号链接和系统垃圾文件。
- 迁移报告位于：

```text
目标数据/.media-app/migration/data-migrations/
```

## 更换设备

迁移助手可以在另一台 Windows x64 设备上运行，不要求安装 Python 或 .NET。

- 媒体笔记、封面、附件、评分缓存、队列、日志和备份可以复制。
- 文件夹可以更换位置，程序使用相对附件路径。
- 系统代理配置和浏览器本地设置不随数据迁移。
- 豆瓣登录态使用当前 Windows 用户的 DPAPI 加密，只能由同一台电脑的同一
  Windows 用户解密。迁移后需要在新设备重新登录豆瓣。

## 命令行

```powershell
python app\data_migration_gui.py --cli `
  --source "D:\旧版\数据" `
  --destination "D:\新版\数据" `
  --policy newer `
  --preview "D:\迁移预览.json"

python app\data_migration_gui.py --cli `
  --source "D:\旧版\数据" `
  --destination "D:\新版\数据" `
  --apply `
  --plan "D:\迁移预览.json"
```
