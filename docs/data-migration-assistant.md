# 影音库数据迁移助手 1.0.0

用于把旧版本地数据安全合并到新版本。工具不会删除源目录，也不执行同步删除。

## 使用前

1. 关闭影音库桌面版和网页版。
2. 使用 Obsidian 的用户先关闭 Obsidian。
3. 保留旧版本压缩包或整个旧数据目录。
4. 确认磁盘剩余空间大于旧数据和新版目标目录备份的总大小。

## 操作

1. 启动“影音库数据迁移助手.exe”。
2. 选择旧版程序目录或旧版“数据”目录。
3. 选择新版程序目录或新版“数据”目录。
4. 选择同名文件策略：
   - 仅补充缺失文件；
   - 源文件较新时覆盖（推荐）；
   - 始终覆盖同名文件。
5. 点击“扫描并预览”，检查文件列表。
6. 点击“执行迁移”并确认。

程序会自动识别程序根目录下的“数据”子目录。默认迁移：

- `媒体库`（独立版媒体数据）；
- `02-电影阅读`（Obsidian 媒体数据）；
- `attachments`；
- `.media-app`。

如果选择了其他结构，可启用“迁移整个所选文件夹（高级）”。

## 安全规则

- 源目录和目标目录不能相同，也不能互相包含。
- 执行前完整备份目标目录。
- 每个文件先复制到临时文件，校验 SHA256 后再原子替换。
- 预览后源或目标文件发生变化时停止执行，要求重新预览。
- 跳过 `apply.lock`、临时文件、符号链接和系统垃圾文件。
- 迁移报告位于：

```text
目标数据/.media-app/migration/data-migrations/
```

## 命令行

```powershell
python app\data_migration_gui.py --cli `
  --source "D:\旧版\数据" `
  --destination "D:\新版\数据" `
  --policy newer `
  --preview "D:\迁移预览.json"

python app\data_migration_gui.py --cli `
  --source "D:\旧版\数据" `
  --destination "D:\新版\数据" `
  --apply `
  --plan "D:\迁移预览.json"
```
