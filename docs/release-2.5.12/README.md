# 影音库 2.5.12 独立版豆瓣模块

发布日期：2026-11-08

独立版不再依赖 Obsidian 才能使用完整的豆瓣登录态。添加媒体窗口新增：

- 内置豆瓣登录窗口。
- 从 Obsidian 豆瓣插件 `data.json` 导入登录态。
- 清除本机登录态。
- 登录状态自动进入 `/api/search`、封面代理和豆瓣详情读取。

登录 Cookie 使用当前 Windows 用户的 DPAPI 加密，API 和日志均不会返回
或记录 Cookie 内容。分享包不包含任何个人登录信息，使用者需要在首次使用时
自行登录或导入插件的 `data.json`。

公开搜索仍作为未登录回退，因此升级不会降低原有可用性。

本版同时修复右侧自绘滑轨：滑块现在支持鼠标拖动、点击轨道跳转、
滚轮和键盘操作，并与页面滚动位置实时同步。
