# 影音库 2.0 · 2.5.9

发布日期：2026-11-08

## 本版内容

- 新建和豆瓣导入改为“立即保存 Markdown，后台补外部评分”。
- 条目创建不再依赖 IMDb、Rotten Tomatoes、Metacritic 或 Wikidata 可用。
- 评分任务持久化到 `.media-app/ratings/queue.json`。
- 后台任务按 5 秒、15 秒、1 分钟、5 分钟、15 分钟、1 小时退避重试。
- 应用重启后自动恢复 `queued`、`retry` 和被中断的 `running` 任务。
- 重复添加已有条目时，会把缺失评分重新加入后台任务。
- 评分任务写入仍使用修订号校验、单文件锁和原子替换。
- 抓取失败不生成猜测值，不显示 `0` 分占位。
- UI 会提示“外部评分将在后台更新”，并在任务完成后自动刷新当前详情。

## 新增接口

- `GET /api/ratings?path=<Vault 相对路径>`：读取评分任务状态。
- `POST /api/retry-ratings`：手动把指定条目的缺口重新排队。

评分队列只是辅助任务数据；Markdown 仍是唯一正式数据源。
