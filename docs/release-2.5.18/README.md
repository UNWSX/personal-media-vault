# 影音库 2.5.18

发布日期：2026-11-08

本版本在 2.5.17 的基础上继续修复评分、启动、进程和安装包体验问题。

普通用户请下载 Windows 独立版；只有已经使用 Obsidian、并准备更新 `.media-app`
的用户才需要 Obsidian 修复版。

主要变化：

- 《无职转生Ⅱ》的 Part 1、Part 2 使用固定 IMDb 编号和独立季/Part 查询。
- IMDb 自动补分使用与批量工具相同的标题别名规则。
- 详情页在网络评分缺失时显示“重新补全网络评分”按钮。
- 关闭所有网页标签后，本地服务会自动退出。
- 关闭桌面窗口会结束当前连接的服务，避免残留后台进程。
- 独立版恢复原有窗口、任务栏图标。
- 根目录提供桌面版和本地网页版两个启动入口。

本版本不执行真实 Vault 迁移，不修改 Markdown 数据格式。
