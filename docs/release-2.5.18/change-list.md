# 2.5.18 修改清单

- `app/server.py`
  - 自动补分接入 IMDb 标题别名表。
  - 新建、豆瓣导入、后台重试与手动重试直接调用批量评分增强工具的同一规则引擎。
  - 自动补分不再维护单独的动画别名、Wikidata、分季/Part 和来源匹配逻辑。
  - 批量工具新增精确单文件筛选，供自动补分复用。
  - 《无职转生Ⅲ》接入固定 IMDb 系列编号和第三季规则。
  - Bangumi/AniList 增加瞬时网络失败重试。
  - 动画英文桥接依次尝试原名、中文名和 Bangumi 原始标题。
  - 注册入口模块别名，避免 PyInstaller 窗口版重复导入 `server` 后扫描错目录。
  - 恢复豆瓣图片在 `img1`–`img9` 明确白名单之间的同路径重试。
  - 单张图片返回 403 或反爬 HTML 时继续尝试下一台已批准主机。
  - 独立版日志、备份和评分队列改存于“数据/.media-app”。
  - 网页版模式增加活动心跳和离页自动退出。
- `app/web/app.js`
  - 网页关闭时通知本地服务。
  - 网络评分缺失时提供一键重新补分。
- `shell/Program.cs`
  - 服务实例版本同步为 `2.5.18`，避免复用旧后台。
  - 桌面窗口关闭时结束当前连接的服务，包括网页版启动的服务。
- `launcher/WebLauncher.cs`
  - 等待服务就绪后再打开浏览器。
  - 使用 `--web-mode` 启动服务。
  - 复用服务前校验应用标识、版本、协议、实例 UUID 与 Vault。
- 发布包
  - 恢复 `app.ico`，修复主窗口和任务栏图标。
  - 桌面版、网页版入口放置在根目录。
  - 运行组件统一放入“程序”目录。
  - Obsidian 批量工具统一放入“工具”目录。
- `tests/test_api_phase1.py`
  - 验证自动评分为批量规则引擎的精确单文件调用。
  - 验证封面主机轮换不越过精确白名单，并在 403/HTML 后继续重试。
- `tests/test_enhanced_ratings.py`
  - 验证《无职转生Ⅱ》Part.1、Part.2 与《无职转生Ⅲ》在自动补分和
    批量预览中得到相同结果。
  - 验证 Bangumi/AniList 瞬时失败重试和多标题英文桥接。
