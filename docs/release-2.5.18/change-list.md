# 2.5.18 修改清单

- `app/server.py`
  - 自动补分接入 IMDb 标题别名表。
  - 新建、豆瓣导入、后台重试与手动重试直接调用批量评分增强工具的同一规则引擎。

  - 网页版模式增加活动心跳和离页自动退出。

  - 网页关闭时通知本地服务。

  - 使用 `--web-mode` 启动服务。
- 发布包

  - 桌面版、网页版入口放置在根目录。

- `tests/test_api_phase1.py`

- `tests/test_enhanced_ratings.py`
