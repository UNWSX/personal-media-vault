# 2.5.18.1 修改清单

- `app/server.py`
  - 将自动评分需要的主标题、豆瓣原名、动画桥接、Wikidata 稳定 ID、
    分季/Part、平台查询缓存和写回计划直接内建到自动评分入口。
  - 删除自动入口对 `batch_enhanced_ratings.build_plan()` 的调用。
  - 旧笔记没有 `originalTitle` 时，优先使用豆瓣 ID 获取原名。
  - IMDb 的多个精确候选中，只有在最佳搜索排名至少领先其他候选 5 倍时
    才自动选分；接近排名继续判为歧义。
  - 访问限制任务从永久 `blocked` 改为冷却一小时自动重试。
  - 启动评分 Worker 时自动恢复旧版遗留的 `blocked` 任务。
- `app/web/compat_logic.js`
  - 修复数字前缀系列标题在去重后缀后误回退原始标题的问题。
- `tests/`
  - 验证自动评分不调用批量工具。
  - 验证豆瓣 ID 优先用于恢复原名。
  - 验证 IMDb 同名同年候选消歧。
  - 验证访问限制任务自动重排。
  - 验证 `007` 系列按发行日期从旧到新排列。
