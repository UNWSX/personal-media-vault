# 影音库 2.0 · 2.5.2 正式版

发布日期：2026-11-07

## 本版内容

- 保留 2.5.1 的界面修复和二元完成状态。
- 详情页移除“我的均分”摘要。
- 状态 Callout 在值为空时安全补写；带额外说明的非空 Callout 仍保持原样。
- 修复 Rotten Tomatoes 旧私有接口失效的问题，改用站点当前的公开搜索索引。
- Rotten Tomatoes 自动查询和批量补全只接受类型、规范化标题、年份和候选唯一性全部匹配的结果。
- 新增 `影音库烂番茄工具.exe`，支持只读预览、人工可读报告、检查点缓存和安全执行。
- 修复豆瓣插件单独保存的 Cookie 未被读取的问题；Cookie 只在本地请求中使用，不写日志。

## 烂番茄批量结果

真实 Vault 的 197 条电影/剧集预演结果：

- 可靠匹配并写入：93
- 无可靠匹配：103
- 歧义候选：1
- 写入失败：0
- 外部修改冲突：0

93 篇仅增加 `rottenTomatoesScore` 字段。正文、附件、链接和其他 YAML 字段保持原样；
103 条无匹配与 1 条歧义记录未被修改。

完整清单和报告随安装包及备份目录提供。

## 兼容性

- API 版本仍为 `2.0.0`，协议版本仍为 `1`。
- Markdown 目录、文件名、正文和 Obsidian 链接不变。
- 旧字段与旧 API 参数继续保留。
- 本版不执行新的数据模型迁移。

## 已知限制

- Rotten Tomatoes 没有可靠英文标题、没有收录、年份不一致或存在多个同标题候选时，不会猜测写入。
- 这些条目保留在“待确认清单”，以后可人工核对或重新运行预览。
