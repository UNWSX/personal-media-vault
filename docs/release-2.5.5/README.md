# 影音库 2.0 · 2.5.5 正式版

发布日期：2026-11-07

## 本版内容

- 使用 Wikidata 稳定标识补全中文片名、日文片名和特摄作品的 IMDb/烂番茄数据。
- 通过作品编号直接读取 IMDb 与 Rotten Tomatoes，减少标题翻译导致的漏匹配。
- 支持用父系列英文名派生特摄剧场版标题，再补查 IMDb。
- Bangumi 查询在主标题失败时会改用豆瓣原始标题重试。
- 增加 `--missing-only`，可只扫描缺少 IMDb 或烂番茄评分的条目。
