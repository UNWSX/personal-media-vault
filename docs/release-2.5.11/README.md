# 影音库 2.0 · 2.5.11 独立分享版修复

发布日期：2026-11-08

## 修复内容

- 修复 Windows 下多个服务实例同时占用同一个 `8765` 端口的问题。
- 服务端口现在使用独占绑定；端口已占用时会尝试下一个端口。
- 独立版窗口固定使用程序旁 `数据` 目录，并据此寻找对应服务实例。
- 避免误连正在运行的其他影音库服务。

该修复同时适用于 Obsidian 版。仓库另生成完整可替换的 Obsidian
修复包，但本次没有覆盖现有安装，也没有修改真实 Vault。

运行环境：

- Windows 10/11 x64
- Microsoft Edge WebView2 Runtime
- 本分享包自带 .NET 7 运行时
